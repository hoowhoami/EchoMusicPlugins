# 界面与播放控件

把原来的“界面元素隐藏”和“播放控件排序”合并为一个插件，统一管理三部分：

- 侧边栏：按“发现音乐”“我的乐库”“歌单”分组显示，图标点亮表示显示，虚影表示隐藏；只能在同一分类内拖动排序。
- 首页播放控件：按左区、前中区、后中区、右区排列，直接点击图标切换显示状态。
- 播放器页控件：与首页控件相同，但包含评论和弹幕按钮。

播放、上一首、下一首始终固定在中区，不可移动；“固定”标记显示在固定控件组标题处，三个固定控件本身与其他控件使用相同的图标、文字高度和底部基线。设置面板使用接近全屏的横向预览，每个页面的左区、中区、右区按实际播放栏排列在同一行；中区按控件内容收缩，左、中、右大区整体居中并保持紧凑间距。拖动控件时会显示以鼠标指针为中心的控件图标虚影。空区仍保留一个虚线控件位，方便继续拖入控件。左区使用统一的小规格控件槽位，中区和右区使用统一的大规格槽位。播放器页包含 beta.5 新增的“换肤”控件，并使用主程序实际图标。

排序使用指针拖动并锁定指针捕获，拖到目标控件前半段表示放置到前面，后半段表示放置到后面；拖到区域空白处则追加到该区域末尾，避免原生拖放事件在设置面板重渲染后丢失。

插件只移动和标记主程序已经渲染的 DOM，不修改主程序源码。

插件要求 EchoMusic `2.3.2-beta.4` 或更高版本。旧宿主缺少 beta.4 的插件运行能力，无法提供可靠的控件识别与布局，因此不再兼容 beta.3。新版本增加的控件会按当前页面实际 DOM 结构识别；不存在的控件会被跳过。
