# MV 功能优化

优化 EchoMusic 的 MV 详情页：

- 将接口返回的每个 MV 版本渲染为紧凑的竖向信息卡片，横向排列；超出可视区域时可用鼠标拖动或触控横向滚动，点击卡片即可选择。
- 隐藏主程序原本只能通过“上一版 / 下一版”切换的单个详情卡片。
- 隐藏原“视频片源”栏。
- 不显示画质选项，始终优先选择最高分辨率的 H.265；无 H.265 时选择最高分辨率的 H.264。
- 时长显示在作者信息下方。搜索结果打开的单个 MV 仅在能通过视频详情找到歌曲 ID、且该歌曲的版本确实包含当前 MV 时才启用多版本界面；无法核实时保留原页面。

插件使用 EchoMusic 的酷狗视频 API 获取版本信息，实际视频加载和播放仍由主程序完成。

插件不声明主程序最低版本。旧宿主缺少酷狗 MV 接口时，会保留主程序原有 MV 页面并提示接口不可用，不会阻断 EchoMusic 启动。
