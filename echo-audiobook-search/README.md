# 听书搜索助手

让 EchoMusic 的「专辑」搜索能找到有声书。

酷狗的有声书在搜索里是单独一类：一本书是一个专辑，一章是一条音频。
EchoMusic 默认只搜音乐专辑，所以在应用里搜《夜的命名术》这类有声书是空的；
本插件把这类专辑一起纳入搜索，点进去就是原有的专辑页，章节、分页、播放都和普通专辑一样。

## 三个开关（只会亮一个）

- **混合搜索**：音乐专辑和有声书一起出现（默认）
- **只看有声书**：专辑列表里只保留有声书
- **关闭**：保持主程序默认的搜索范围

## 诊断信息（默认收起）

设置页最下面有一行「诊断信息」，默认折叠。点开才能看到：

- 已改写多少次搜索请求；
- 最近 8 条搜索请求的地址与参数（`✓` 表示这条被改写过）；
- 「刷新」「清空记录」两个按钮。

平时不用管，搜不到书的时候再展开，把内容发给作者排查。

## 安装

设置 → 插件管理 → 打开目录，把 `echo-audiobook-search` 文件夹放进去，然后启用插件、重载应用。
装好后到 设置 → 插件 → 听书搜索助手 里选模式。

## 说明

- 搜索范围变了，能不能听还要看版权：有声书大多是会员或付费内容，搜到不等于能自由播放。
- 有声书专辑的副标题仍沿用「N 首歌曲」的说法，实际是 N 章。
