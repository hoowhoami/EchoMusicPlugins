# 频谱可视化

把 EchoMusic 当前播放音频的频谱自然地嵌入播放器界面。设置页与主程序共用语义色和控件风格，频谱默认跟随主程序主题色，并自动适配明暗主题。

## 功能

- 在主窗口 PlayerBar 中显示频谱背景。
- 在 Mini 播放器卡片中显示频谱背景。
- 在歌词页底部控制栏上方显示频谱区域。
- 三个显示位置可以分别开关。
- 支持柱状、波形、混合、雾状和中心频谱五种样式。
- 雾状频谱根据频段生成三层柔光雾带，支持雾气浓度、雾化柔度与流动速度调节；空闲时保持低幅呼吸效果。
- 中心频谱使用更高频段密度，并支持调节频谱条宽度；数值越小，柱条越细密。
- 支持刷新率、频段数量、FFT、平滑、频率分布、配色、不透明度与填充高度等设置。
- 配色默认跟随频谱挂载区域的主程序主题色，也可切换为极光、余烬、冰蓝或单色。
- 背景光晕独立开关，默认关闭，只保留频谱本身。
- 雾状模式不请求波形数据并最高按 24 FPS 绘制，兼顾多个显示位置同时开启时的性能。
- 设置页提供“恢复默认”，可一次重置显示位置、视觉与采样参数。

## 样式说明

- **雾状**：柔和、连续的多层频段云雾，适合作为低干扰背景。
- **中心频谱**：低频居中、向两侧镜像展开的高密度细圆角柱，带连续插值、攻防平滑与边缘渐隐。
- **混合**：波形与频谱柱叠加，信息最丰富。
- **柱状**：清晰展示各频段能量。
- **波形**：直接展示时域波形，节奏响应更鲜明。

## 要求

- EchoMusic `>=2.3.1-beta.21`
- 主程序需要支持 `ctx.audio.spectrum`

## 安装

在线安装：在 EchoMusic 的“插件管理”中添加本仓库插件源，然后安装“频谱可视化”。

手动安装：将 `spectrum-visualizer` 整个文件夹复制到 EchoMusic 插件目录，刷新并启用插件。
