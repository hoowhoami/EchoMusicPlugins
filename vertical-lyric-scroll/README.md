# 竖幅歌词

独立桌面歌词浮窗，以竖排（vertical-rl）方式展示当前播放歌词，支持逐字（YRC）高亮。

## 功能

- 独立透明浮窗，竖排文字书写方向（从上到下、从右到左）。
- 逐字歌词（YRC）高亮，进度由本地时钟 + `ctx.nowPlaying` 锚点插值推算，对齐主程序桌面歌词的高亮逻辑。
- 当前句居中，上一句/下一句渐隐展示，支持翻译/音译副列。
- 浮窗位置钉选（锁定后不可拖动）、置顶、点击穿透、深浅主题跟随。
- 设置面板调节尺寸（宽 180-280 / 高 360-760）、不透明度、字号、主题。
- 跨窗口设置同步使用 `BroadcastChannel`，消息内容只发送归一化后的普通对象。

## 说明

浮窗通过 `contributes.windows` 声明，由主进程创建；插件入口在 `index.js`，浮窗入口在 `scroll.js`。

窗口拖动通过 JS pointer 事件 + `ctx.window.move` 实现（不使用 `-webkit-app-region: drag`），以规避透明窗口在 Windows 上的拖动残影；拖动时传完整 `{ x, y, width, height }`，width/height 使用按下时记录的固定值，避免 DPI 舍入导致尺寸漂移。
