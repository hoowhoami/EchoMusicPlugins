# 视频主题 Demo

从 EchoMusic 的插件管理导入本目录并启用，在主题中心选择“视频主题 Demo”，展开“插件专属设置”。插件启用不会自动应用主题；侧栏 `+` 中仍可选择“主题工作台”快捷卡片。

需要包含新文件授权与下载 API 的 EchoMusic 构建，当前开发版本为 `2.3.2-beta.10`。旧版本的同名插件原先演示晨雾/暮色，升级后需重新选择视频主题。

## 本地视频

点击“选择本地视频”，通过系统文件选择器授权一个视频文件。选择不会复制大视频，设置保存 `FileRef`，背景组件每次挂载调用 `openMedia()` 获取临时播放地址。文件保留原位置即可离线使用；文件移动、删除或撤销授权后，需要重新选择。

## 外置视频下载

输入 HTTP/HTTPS 视频直链，点击“下载并使用”。示例调用 `ctx.net.download()` 流式写入插件私有 data 目录，展示进度并提供取消。只有完整下载、提交后才使用新文件，不把远端 URL 直接作为视频 src。

关闭设置不会取消下载，但晚到结果不会修改已卸载的主题设置。重新打开本主题设置后点击“使用已下载视频”；已应用的文件引用会保存，重启后无需联网即可播放。尚未应用的下载结果只保留在本次插件运行中，此 demo 不实现资源目录、质量清单或重启后任务恢复 UI。

下载目标使用独立文件名，避免覆盖正在播放的视频。不要求服务端提供额外资源清单、大小或哈希；正式主题包可按实际发布信息增加校验、质量选择、续传和素材管理。

## 播放与生命周期

视频静音、循环、保持原速，支持铺满/完整显示和遮罩强度。宿主 `motionEnabled` 关闭时暂停（窗口不可见或系统要求减少动态效果），恢复时继续播放。换素材、离开主题或禁用插件时释放媒体租约；异步晚到的旧地址也会释放。

首次没有视频时显示渐变底色，不自动联网。仓库不捆绑视频，MP4/H.264 是常见选择，具体支持取决于宿主解码能力。4K 可使用同一接口，但流畅度取决于素材编码与设备性能。

“清除选择”仅重置当前主题引用，已下载文件保留。卸载默认保留私有 data，可选择同时删除；用户选择的外部视频不会被删除。
