# 开机自启管家

请先在应用内开启【开机自启动】，同时开启【启动时最小化到托盘】效果更佳，体验更无感。

开机自启之后，如果本周期已经签过到、而且你没在听歌，就在启动后的几分钟里安静地退出应用，把内存让出来。
退出之前先等一会儿，再弹一张小卡片，上面只有一句话和两个按钮：点「保留」今天就不会再自动退出。

## 怎么认出"这次是开机自启"

读系统告诉应用的开机时长：只有开机后没多久就启动的应用，才算开机自启。
白天用着电脑临时打开、或者中途重载插件，开机时长早就超过窗口了，一律不介入。

所以这里填的窗口，含义是"开机后多久内启动算自启"，不是"应用自己跑了多久"。

> 这个能力依赖客户端的「读取开机时长」接口。旧版客户端没有这个接口时，插件会自动退回按「应用启动后 N 分钟内」判断（窗口含义变成应用运行时长），状态信息里会写明用的是哪种判断。

## 三个时间

每个时间四档，点一下立即生效（下次启动生效），选中的那档是绿色的。

| 设置项 | 可选 |
|---|---|
| 开机后多久内算自启 | 30 秒 / 1 分钟 / 5 分钟 / 10 分钟 |
| 退出前静默等待 | 15 秒 / 30 秒 / 60 秒 / 90 秒 |
| 退出倒计时 | 3 秒 / 5 秒 / 10 秒 / 15 秒 |

底下「状态信息」默认展开：本周起算日、当前判定、上次自动退出、本次启动（开机后多久启动、算不算自启），以及重新检查、重置记录两个按钮；不想看就点一下收起。

## 它怎么判断"本周期已签到"

读取签到插件留下的期次编号，两条任一成立就算本期已签：

1. 期次编号比上次记录的大了（编号只会在签到成功后前进）；
2. 编号没变，但上次见到它的那一周就是本周三开始的那一周。

读不到编号就什么都不做——宁可不管，也不会误关。

## 不会做的事

- 不会在开机自启之外的场合动手（白天手动打开、重载插件都不碰）；
- 正在播放时一律不动；
- 同一天只自动退出一次，你点过「保留」当天也不会再来打扰。

## 一些说明

- 本插件不申请任何能力（清单里 `capabilities` 为空），也不需要网络。
- 退出用的是应用自己的「退出」通道，和点菜单退出等价。
- 不想用时在插件管理里停用即可。
