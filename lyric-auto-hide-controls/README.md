# Lyric Auto-Hide Controls 🎵

全屏歌词界面下，鼠标静止后自动隐藏底部控制栏，实现沉浸式听歌体验。

## 功能

- 🖱️ **鼠标静止 2 秒**（可调）→ 控制栏自动淡出
- ✨ **鼠标一动** → 控制栏立即恢复显示
- 🎯 **进度条区域** hover 时不隐藏
- ⌨️ **ESC 键** 手动切换隐藏/显示
- 🖥️ **鼠标移出窗口** 自动隐藏（全屏场景）
- ⚙️ 支持设置面板调节隐藏延迟（0.5s ~ 5s）

## 安装

1. 打开 EchoMusic → 设置 → 插件 → **打开插件目录**
2. 把 `lyric-auto-hide-controls` 文件夹放进插件目录
3. 回到插件列表，点击 **重载**
4. 在列表中启用「沉浸式歌词隐藏」
5. 进入全屏歌词界面，静止鼠标即可体验

## 设置

插件提供设置面板，可调节：
- **启用/禁用**：开关控制
- **隐藏延迟**：0.5s ~ 5s 滑块调节（默认 2s）

## 注意

- 仅在**全屏/沉浸歌词界面**下生效，普通播放界面不影响
- 进度条 hover 时控制栏保持可见，不影响拖拽进度
