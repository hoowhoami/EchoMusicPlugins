# 滚动助手

为 EchoMusic 的长页面补充“到底部”按钮。

## 功能

- 在当前页面还没有滚到底部时显示“到底部”按钮。
- 切页时重新绑定当前滚动容器；歌词覆盖页打开期间隐藏，兼容透明背景。
- 按钮与主程序“回到顶部”共用尺寸变量，默认为 32px、6px 圆角矩形，箭头为 16px；出现/消失使用 120ms 淡入淡出。
- 使用宿主 Tooltip 展示提示，支持键盘焦点；遵循系统“减少动态效果”设置。
- 点击后直接滚动到当前页面底部。
- 如果宿主的“回到顶部”按钮没有显示，会自然占用它的右下角位置；显示后会平滑上移避让。
- 提供插件设置，可开关按钮、调整底部隐藏阈值和避让行为。

插件依赖 EchoMusic `>=2.2.6-beta.20`，因为它使用宿主提供的稳定滚动容器 API `ctx.scroll`。
