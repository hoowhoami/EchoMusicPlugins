# old-xiami-lyric-styles

将 EchoMusic 页面歌词替换为旧版虾米歌词风格。

## 效果

- 当前行高亮放大，带文字辉光
- 其他行渐隐，随距离增加透明度和模糊递增
- 左侧当前行指示器（圆点/竖线）
- 平滑过渡动画
- 可调节各项参数

## 设置

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 启用动效 | 开关控制 | 开启 |
| 当前行标记 | 左侧指示器样式 | 圆点 |
| 当前行放大 | 100-150 | 115 |
| 辉光强度 | 0-80 | 38 |
| 其他行透明度 | 20-80 | 45 |
| 滚动过渡 | 100-1200ms | 420 |
| 行间距 | 1.5-3.5 | 2.1 |
| 对齐方式 | 左对齐/居中对齐 | 居中对齐 |
| 歌词边距 | 0-288 | 72 |
